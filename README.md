# 507games · 骑士试炼白模

供朋友共同开发的 Unity 平台战斗白模。此存档对应最后试玩的**含上层伸缩地刺版本**，包含冲撞破门、中继钥匙任务、安全缺口、地下双路线、必经升降台、多层 Boss、剧情道具及末端返回上层。

## 打开试玩

1. 安装 Unity **6000.6.5f1**（Unity 6.6）及 Windows Build Support。
2. 克隆本仓库，在 Unity Hub 中添加仓库根目录。
3. 等待首次素材导入，打开 `Assets/Scenes/DodgeStudy.unity`，按 Play，再按 Enter 开始。
4. `LowerPassage.unity` 会由主场景自动叠加加载；不要只启动地下场景。

操作：A/D 移动，Space/W 跳跃（松开可短跳），J/Shift 翻滚，K/鼠标左键攻击，E 交互，Enter 复活，R 重开，Esc 暂停，F1 判定框，Tab 慢放。

## 当前内容

- 上层约 128 米，六段遭遇；第一处木门需要诱敌冲撞。
- 终点取得信号钥匙，返回中继交付，开启终门及通往地下的安全缺口。
- 上层中段伸缩地刺有安全、预警、有效、回缩阶段。
- 地下保留高低两路，末端前必须搭自动升降台到达高处出口。
- Boss 场宽 40 米，八块错落平台；冲撞、地面冲击、锁定落点三招。
- 击败 Boss 后获得旧日记录匣，在地下末端按 E 返回上层。

数值与细节见仓库内的《数值与攻击判定》《Boss白模试玩说明》《必经升降台说明》《上层地刺机关说明》。

## 朋友协作

- 每人使用独立分支，完成后提交 Pull Request，再合入 main。
- 开始工作前同步最新 main，避免多人同时修改同一个 Unity 场景。
- `.meta` 文件必须与素材一起提交；在 Unity 项目窗口中移动素材以保留引用。
- 美术替换模块的视觉子节点，保留 WhiteboxPlatform、WhiteboxLift、WhiteboxSpikes 和标记根节点。
- 关卡进度由 KnightLevel 统一持有；生命、伤害和判定尺寸集中在 `Assets/Resources/CombatTuning.asset`。
- 上层主要由脚本生成，地下平台来自场景模块。修改前先读《白模填充指南》。
- 缓存、临时文件和本地试玩构建不提交。仓库保留可编辑工程和素材。

## 构建

停止 Play 并保存场景，使用菜单 **白模工作台 → 构建试玩（保留现有场景）**。输出为 `Build/DodgeStudy.exe`。

日常构建用 `BuildStudy.BuildExisting`。**不要使用 `BuildStudy.Run`**，它会重新生成默认白模并覆盖关卡编辑。

## 来源与版本说明

现有占位角色：Hero Knight - Pixel Art / Sven Thole；Zombie / Pxltiger。素材与已有 `.meta` 引用随工程保留。本仓库未另行授予第三方素材许可。

上传准备只在独立工程副本中恢复最后试玩版的地刺接线，使源码与该试玩版一致；原本地工作目录未被修改。当前版本的地刺仍是待试玩评估的内容，后续是否保留由团队决定。
